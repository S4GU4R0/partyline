## What This Is

You know how calling for help usually means waiting on hold? This is the other line.

211-alternative for off-label survival infrastructure. Finds resources that prioritize people who have the least — by matching barriers to solutions, not disqualifying people for having problems.

## Stack

- TypeScript + MCP SDK
- SQLite (local-first)
- HTTP transport (localhost:3000)
- No cloud, no Docker, no Kubernetes

## Setup

```bash
git clone <repo>
cd partyline
npm install
npm run dev
```

That's it. Server runs on `localhost:3000`.

## The Vibe

Bro-helpful, no-bullshit, high-trust, risk-aware.

When we say "finds you spots that won't waste your time," we mean it. We're not here to send you through four phone trees to find out you don't qualify.

## Risk

This helps you find off-label solutions outside mainstream systems. You still gotta know your local situation. We give you the who and how — you make the call on risk.

## API

Three tools, no more:

- `search_resources` — find by need + location
- `check_eligibility` — barrier matching (what you need vs what they actually handle)
- `assess_risk` — risk level + notes for off-label usage

## Note

This is v0. Messy but functional. No tests yet. It works or it doesn't — check the logs.
